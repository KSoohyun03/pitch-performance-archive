# PITCH 공연 아카이브

PITCH의 공연 안내, 공연별 팀과 셋리스트, 방문자 소감을 기록하는 정적 웹사이트입니다.

## 실행하기

`index.html` 파일을 브라우저에서 열면 사이트를 볼 수 있습니다. 별도의 설치는 필요하지 않습니다.

## 실제 공연 정보로 바꾸기

`script.js` 위쪽의 `shows` 배열에서 예시 공연 데이터를 실제 공연명, 날짜, 장소, 참여 팀, 팀원, 셋리스트, 소개 문구로 교체하세요. 각 공연의 `teams` 안에 팀별 정보가 들어갑니다. 팀은 `name`(팀명), `members`(팀원), `songs`(그 팀의 셋리스트) 항목을 가집니다. 한 공연에 3~6개의 팀 객체를 넣으면 공연 상세 화면에 팀별 카드로 표시됩니다. `index.html`의 밴드 소개 문구도 필요에 맞게 수정하면 됩니다.

공연 목록에서 카드를 선택하면 해당 공연의 상세 화면으로 이동합니다. 상세 화면에는 팀별 멤버와 셋리스트가 함께 표시되고, 아래 소감란은 해당 공연에 연결됩니다. 방문자가 남긴 소감은 공연별로 현재 브라우저에 저장됩니다.

## 소감 저장 안내

소감 작성 기능은 방문자가 직접 입력하고 제출해볼 수 있으며, 현재 브라우저의 `localStorage`에 공연별로 저장됩니다. 따라서 방문자 본인의 브라우저에서만 보이고 다른 방문자나 운영자에게 공유되지 않습니다. 실제 공개 방명록으로 운영할 때에는 Firebase, Supabase 같은 데이터 저장 서비스를 연결하고 개인정보 안내와 삭제 방법을 함께 마련해야 합니다.

## GitHub Pages / Netlify

이 프로젝트는 빌드 도구가 필요 없는 HTML, CSS, JavaScript 사이트입니다. 세 파일(`index.html`, `styles.css`, `script.js`)과 README를 GitHub 저장소 최상위에 올린 뒤 Netlify에서 해당 저장소를 연결하면 됩니다. 빌드 명령은 비워두고, 배포 폴더는 `.` 또는 저장소 루트로 설정합니다.

## 과제에서 설명할 알고리즘

공연 목록의 최신순, 오래된 순, 제목순 정렬에 병합 정렬(Merge Sort)을 직접 구현해 적용했습니다. 목록을 반씩 나누고 정렬된 두 부분을 다시 합치며, 일반적인 시간 복잡도는 O(n log n)입니다.
