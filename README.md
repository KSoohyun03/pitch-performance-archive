# PITCH 공연 아카이브

PITCH의 공연 안내, 공연별 팀과 셋리스트, 방문자 소감을 기록하는 정적 웹사이트입니다.

## 실행하기

`index.html` 파일을 브라우저에서 열면 사이트를 볼 수 있습니다. 별도의 설치는 필요하지 않습니다.

## 공연 자료 수정하기

공연 데이터는 `script.js`의 `shows` 배열에서 관리합니다. 각 공연에는 날짜, 공연명, 장소, 대표 포스터, 상세 포스터 목록, 팀별 멤버와 셋리스트를 입력합니다. 포스터 파일은 `assets/` 폴더에 두고, 경로를 공연 데이터에 연결합니다.

공연 목록에서 카드를 선택하면 공연 상세 화면으로 이동합니다. 상세 화면에는 포스터와 팀별 멤버, 셋리스트가 표시됩니다. 방문자가 남긴 소감은 공연별로 현재 브라우저에 저장됩니다.

## 소감 저장 안내

소감 작성 기능은 방문자가 직접 입력하고 제출해볼 수 있으며, 현재 브라우저의 `localStorage`에 공연별로 저장됩니다. 따라서 방문자 본인의 브라우저에서만 보이고 다른 방문자나 운영자에게 공유되지 않습니다. 실제 공개 방명록으로 운영할 때에는 Firebase, Supabase 같은 데이터 저장 서비스를 연결하고 개인정보 안내와 삭제 방법을 함께 마련해야 합니다.

## 정렬 알고리즘

공연 목록의 최신순, 오래된 순, 공연명순 정렬에 병합 정렬(Merge Sort)을 직접 구현해 적용했습니다. 목록을 반씩 나누고 정렬된 두 부분을 다시 합치며, 시간 복잡도는 O(n log n)입니다. 별도의 성능 비교 화면은 사이트에 두지 않고, 성능 측정 결과는 과제 설명에 기록합니다.

## GitHub Pages / Netlify

이 프로젝트는 빌드 도구가 필요 없는 HTML, CSS, JavaScript 사이트입니다. `index.html`, `styles.css`, `script.js`, `README.md`와 `assets/` 폴더를 저장소에 올리면 됩니다. Netlify를 사용할 경우 빌드 명령은 비워두고, 배포 폴더는 `.` 또는 저장소 루트로 설정합니다.
